## 数据管线

完成并理解了 Severstal 语义分割训练数据管线：

- 从稀疏 CSV 中读取每张图片的四类 RLE 标注。
- 未出现在标注字典中的图片使用四个空 RLE，表示正常图片。
- 使用列优先、从 1 开始编号的规则解码掩码。
- 图片使用双线性插值缩放，掩码使用最近邻插值，避免产生不存在的类别值。
- 图片张量形状为 `[3, H, W]`，掩码张量形状为 `[4, H, W]`。
- `DataLoader` 批次形状为图片 `[B, 3, H, W]`、掩码 `[B, 4, H, W]`。

真实样本 `002fc4e19.jpg` 在 `512 x 128` 输入下得到：

```text
image: [3, 128, 512]
mask: [4, 128, 512]
mask values: [0.0, 1.0]
positive pixels: [244.0, 187.0, 0.0, 0.0]
```

这说明该图片包含类别 1、2 的缺陷，不包含类别 3、4。

## 模型与训练

模型采用 U-Net 解码器和 ResNet18 编码器：

- 输入：`[B, 3, H, W]`
- 输出 logits：`[B, 4, H, W]`
- 四个输出通道分别预测四类缺陷，每个像素允许同时属于多个类别。
- logits 在推理或评估时经过 `sigmoid` 和阈值处理。

训练过程使用：

- AMP 混合精度，降低显存占用并加速训练。
- BCE + Dice 或 Focal + Dice 损失。
- 每轮分别训练和验证，验证阶段不更新参数。
- 按验证集 macro Dice 保存最佳 checkpoint，同时保存 latest checkpoint 和训练历史。

## 类别感知采样

类别感知采样根据稀有类别提高样本权重，但不改变验证集和测试集分布。

### sampling power 0.5

```text
sample-weight range: 0.758 - 3.682
best macro Dice: 0.3841
class Dice: [0.3810, 0.0000, 0.6141, 0.5411]
```

类别 1、3、4 得到改善，但类别 2 仍未学会。

### Focal + Dice

使用 `sampling_power=0.5`、`focal_alpha=0.75`、`focal_gamma=2.0`：

```text
best macro Dice: 0.2859
class Dice: [0.1541, 0.0963, 0.4948, 0.3982]
```

类别 2 开始产生预测，但 precision 只有约 `0.0532`，误报过多，整体性能下降，因此不作为当前最佳方案。

### sampling power 0.75

恢复 BCE + Dice，并将类别感知采样强度提高到 `0.75`：

```text
sample-weight range: 0.600 - 6.424
epoch 1 macro Dice: 0.0989
epoch 2 macro Dice: 0.3962
epoch 3 macro Dice: 0.3429
epoch 4 macro Dice: 0.3713
epoch 5 macro Dice: 0.3228
```

第 2 轮最佳 checkpoint 的分类别 Dice 为：

```text
class_1: 0.2238
class_2: 0.3396
class_3: 0.5525
class_4: 0.4688
macro:   0.3962
```

阈值扫描后，全局阈值 `0.70` 的 macro Dice 为 `0.3992`。该实验首次让四个类别都获得有效 Dice，是当前候选模型。

## 结论

- 类别 2 的困难来自数据集本身的类别不平衡，不是数据未下载完整。
- 类别感知采样比直接更换 Focal Loss 更适合当前五轮短训练。
- `sampling_power=0.75` 提高了稀有类别曝光，但权重范围扩大到 `0.600 - 6.424`，训练波动也更明显。
- 最佳结果出现在第 2 轮，说明必须按验证指标保存最佳模型，不能默认最后一轮最好。
- 测试集继续封存，模型选择和阈值调整只使用验证集，避免测试集泄漏。
- 下一步不继续盲目试超参数，而是检查候选模型的预测图、漏检和误检，再决定是否调整损失、采样或训练轮数。
